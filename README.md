# Social Media Monitoring — веб-панель (исходный код)

Исходный код панели мониторинга (Next.js). Здесь только код: сайт из этого репозитория **не публикуется**
(GitHub Pages отключён). Панель собирается статически (`STATIC_EXPORT=1`) и разворачивается вместе с backend
на сервере проекта: один адрес, `/` — панель, `/api/*` — API.

* Вход — один пароль, проверяется сервером (хранится только как argon2id-хеш).
* Сессия — HttpOnly-cookie (`Secure`, `SameSite=Strict`) + CSRF-токен для изменяющих запросов.
* Скриншоты и PDF отдаются только авторизованной сессии.
* В репозитории нет секретов, данных, PDF и скриншотов.

GitHub Actions (`.github/workflows/ci.yml`) только проверяет типы и сборку при каждом push.

## Локальная разработка

```bash
npm ci
SMM_API_URL=http://127.0.0.1:8000 npm run dev        # прокси /api → локальный API
STATIC_EXPORT=1 npm run build                         # статическая сборка в out/ (как на сервере)
```
